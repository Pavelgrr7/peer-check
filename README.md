# PeerCheck

Веб-сервис анонимного взаимного рецензирования лабораторных работ: студент загружает свою работу в PDF, проверяет чужую по чек-листу и после этого получает отзывы на свою.

Студент входит по своей почте и паролю, а другие пользователи видят только случайный псевдоним, который выдала ему система (например, «Скрытный Енот #427»). Подробнее в [контрактах](docs/architecture_contracts.md), раздел «Учётная запись и анонимность».

**Стек:** Python, Streamlit (интерфейс), SQLite (база данных).

## Кто за что отвечает

| Файл | Что в нём | Ответственный |
| :--- | :--- |:--------------|
| `app.py` | Точка входа: настройка страницы и меню | Паша          |
| `screens/home.py`, `screens/submit.py` | Экраны «Как это работает» и «Сдать лабораторную» | Виталина      |
| `screens/login.py`, `screens/review.py` | Экраны «Вход и регистрация» и «Проверить чужую работу» | Егор          |
| `screens/my_reviews.py` | Экран «Мои отзывы» | Кирилл        |
| `database.py` | Работа с базой данных SQLite: работы, рецензии, учётные записи | Кирилл        |
| `roulette.py` | Логика: выдача работ на проверку, проверка отзывов, доступ к отзывам, псевдонимы и пароли, сохранение PDF | Егор          |
| `test_roulette.py` | Автотесты для `roulette.py` (запуск: `python test_roulette.py`) | Паша          |
| `seed_demo_data.py` | Демо-пользователи, работы и рецензии для показа (запуск: `python seed_demo_data.py`) | Кирилл        |

## Как запустить проект локально

1. Склонировать репозиторий и создать виртуальное окружение (подробно в [git_guide.md](docs/git_guide.md)).
2. Установить зависимости: `pip install -r requirements.txt`
3. Запустить приложение: `python -m streamlit run app.py`

Для Виталины: в браузере через [GitHub Codespaces](docs/codespaces_guide.md).
