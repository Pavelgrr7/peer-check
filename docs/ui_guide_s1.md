## В чем суть задачи?
Мы создаем веб-интерфейс на **Streamlit**. Это библиотека Python, где каждый вызов функции сразу рисует элемент на веб-странице.

В первом спринте задача — сделать стартовую витрину: заголовок, приветственный блок и разделение на режимы «Сдать работу» и «Проверить чужую».

---

## Пошаговый план работы:

1. **Синхронизация:** В PyCharm нажми синюю стрелку **Update Project** (`Ctrl + T`).
2. **Открытие файла:** Открой `app.py` и полностью сотри оттуда старый черновой текст.
3. **Стартовый шаблон:** Вставь следующий базовый код:

```python
import streamlit as st

# Настройка вкладки браузера
st.set_page_config(
    page_title="PeerCheck - Анонимная проверка лаб",
    layout="wide"
)

# Заголовок страницы
st.title("PeerCheck: Анонимная проверка лабораторных")
st.write("Платформа студенческого взаимного рецензирования. Проверь чужую лабу — получи отзыв на свою!")

st.divider()

# Боковое меню выбора действия
mode = st.sidebar.radio(
    "Выберите раздел:",
    ["Сдать лабораторную", "Проверить чужую работу", "Мои отзывы"]
)

if mode == "Сдать лабораторную":
    st.subheader("Загрузка новой лабораторной работы")
    lab_num = st.selectbox("Номер работы:", [f"Лабораторная №{i}" for i in range(1, 6)])
    
    # Чекбокс подтверждения анонимности
    anon_confirm = st.checkbox("Я подтверждаю, что удалил(а) титульный лист и имя из файла")
    
    uploaded_file = st.file_uploader("Прикрепите отчет (строго PDF)", type=["pdf"])
    
    if st.button("Отправить на проверку"):
        if anon_confirm and uploaded_file:
            st.success("Работа успешно загружена в пул проверки!")
        else:
            st.warning("Пожалуйста, подтвердите удаление персональных данных и прикрепите PDF-файл.")

elif mode == "Проверить чужую работу":
    st.subheader("Режим взаимного рецензирования")
    st.info("Здесь появится сплит-экран: просмотр PDF слева и чек-лист проверки справа.")

elif mode == "Мои отзывы":
    st.subheader("Статус вашей сданной работы")
    st.write("Отзывы будут разблокированы после того, как вы проверите одну чужую работу.")
```

4. **Проверка:** В терминале выполни `streamlit run app.py`. В браузере откроется рабочий сайт.
5. **Отправка:** Закоммить изменения с сообщением `feat(ui): добавлен стартовый каркас страниц` и нажми **Push**.
