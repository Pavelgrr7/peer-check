# Работа в GitHub Codespaces

Codespaces — это редактор VS Code прямо в браузере. Код, Python и Git работают на серверах GitHub, поэтому на компьютере ничего устанавливать не нужно. Подойдёт любой компьютер с браузером, в том числе в библиотеке.

Это руководство заменяет шаги из `git_guide.md`, в которых упоминается PyCharm.

---

## 1. Первый запуск (делается один раз)

1. Открой [github.com/Pavelgrr7/peer-check](https://github.com/Pavelgrr7/peer-check) и войди в свой аккаунт.
2. Нажми зелёную кнопку **Code** ➔ вкладка **Codespaces** ➔ **Create codespace on main**.
3. Подожди 2–3 минуты. Библиотеки из `requirements.txt` установятся сами, ничего вводить не нужно.
4. Откроется редактор: слева файлы проекта, снизу терминал.

## 2. Каждый следующий раз

1. Зелёная кнопка **Code** ➔ вкладка **Codespaces** ➔ кликни по уже созданному codespace (новый **не** создавай).
2. Перед началом работы забери свежие изменения ребят: слева иконка **Source Control** (третья сверху, ветки) ➔ кнопка **⟳ Sync Changes** (или `...` ➔ **Pull**).

## 3. Запуск сайта

1. В терминале снизу введи:
   ```bash
   python -m streamlit run app.py
   ```
2. Справа снизу всплывёт окно **Open in Browser**, нажми его. Сайт откроется в новой вкладке.
   *(Если окно не появилось: вкладка **Ports** рядом с терминалом ➔ строка `8501` ➔ иконка глобуса).*
3. Остановить сайт: кликни в терминал и нажми `Ctrl + C`.

## 4. Как сохранить и отправить работу (Commit & Push)

1. Слева иконка **Source Control**. В списке **Changes** видны изменённые файлы.
2. Наведи на свой файл (например, `app.py`) и нажми **+** (Stage Changes). Остальные файлы не трогай.
3. В поле **Message** сверху напиши сообщение коммита из задачи.
4. Нажми **Commit**, затем **Sync Changes**. Готово, код на GitHub.

> Кликни по файлу в списке Changes, чтобы увидеть, что именно поменялось: слева старая версия, справа новая.

## 5. Важно помнить

* **Codespace засыпает** примерно через 30 минут без действий. Ничего не теряется, просто открой его снова (пункт 2).
* **Бесплатное время ограничено** (десятки часов в месяц). Закончил работу ➔ на странице репозитория **Code** ➔ **Codespaces** ➔ `...` ➔ **Stop codespace**.
* **Не удаляй codespace**, в котором есть незапушенные изменения: они пропадут вместе с ним.

## Если что-то пошло не так

Сделай скриншот всего экрана и скинь в наш чат в тг. Codespace можно пересоздать за 3 минуты, так что сломать что-то по-настоящему невозможно.
