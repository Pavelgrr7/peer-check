# Зачем База Данных и как работает SQLite

Кажется, что текстовый файл проще: открыл через `open("data.json", "w")`, записал словарь и готово. Но в реальных проектах такой подход приводит к проблемам.

---

## Почему текстовые файлы не подходят для нашего сервиса?

1. Проблема одновременной записи (Конкурентность):
   Ситуация: два студента одновременно нажимают кнопку «Отправить лабу на проверку». Программа попытается одновременно открыть один и тот же файл `data.json` на запись. Итог: один из них затрет данные другого, или файл повредится и превратится в кашу.  
   *База данных умеет выстраивать очередь и безопасно обрабатывать сотни параллельных запросов.*

2. Скорость и память:
   Чтобы в JSON-файле найти лабу студента с ID 500, компьютеру придется прочитать весь файл целиком в оперативную память. Когда лаб станет много, сайт начнет дико тормозить.  
   *База данных находит нужную строчку за доли миллисекунды, не читая весь диск.*

3. Защита от сбоев (Транзакции):
   Что если во время сохранения лабы в файл на компьютере что-то случится с сетью или упадет скрипт? Файл останется недописанным и повредится.  
   *В базах данных есть транзакции: операция либо выполняется успешно, либо полностью отменяется без повреждения данных.*

4. **Строгие типы данных:**  
   База данных не позволит случайно записать текст в поле, где ожидается номер лабораторной работы (число). Это защищает проект от глупых багов.

---

## Как устроена работа с SQLite в Python

В SQLite вся база данных — это **один аккуратный файл** (у нас он будет называться `peercheck.db`).

Вся работа с ней в коде всегда строится по **5 шагам**:

```python
import sqlite3

# 1. Подключение
# Открывает файл базы. Если файла еще нет — SQLite автоматически создаст его сам
conn = sqlite3.connect("peercheck.db")

# 2. Курсор
# Это рабочий инструмент, через который выполняются команды для базы данных
cursor = conn.cursor()

# 3. Выполнение команды
# Передаем курсору команду на языке SQL (например, создать таблицу или добавить запись)
cursor.execute("ТВОЙ_SQL_ЗАПРОС_ЗДЕСЬ")

# 4. Фиксация
# Если не вызвать commit(), изменения останутся в памяти и не сохранятся на диск, так что шаг обязательный
conn.commit()

# 5. Закрытие подключения
# Освобождаем файл, чтобы с ним могли работать другие части программы
conn.close()
```
