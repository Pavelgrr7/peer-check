# Гайд по настройке и основам Git (Спринт 1)

Все основные действия делаются прямо в PyCharm через кнопки на верхней панели и вкладку **Commit** слева.


## 0. Первоначальная настройка проекта (делается один раз)

Если проект еще не скачан на твой компьютер, выполни эти шаги:

### Шаг 1. Клонирование репозитория
1. Запусти **PyCharm**.
2. На стартовом экране нажми кнопку **Clone...** (или в верхнем меню: `File ➔ New ➔ Project from Version Control...`).
3. В поле **URL** вставь ссылку на наш репозиторий:  
   `https://github.com/Pavelgrr7/peer-check.git`
4. В поле **Directory (Папка)** выбери, куда сохранить проект.  
   *(**Важно для Windows:** путь к папке не должен содержать русских букв. Лучше сохранить, например, в `C:\Projects\PeerCheck`, если в имени пользователя Windows есть кириллица).*
5. Нажми кнопку **Clone**.

---

### Шаг 2. Авторизация в GitHub
Когда PyCharm попросит доступ к GitHub (при клонировании или при первой попытке сделать Push):
1. В появившемся окне выбери **Log In via GitHub...**.
2. PyCharm откроет страницу в твоем браузере.
3. Нажми кнопку **Authorize**.
4. Вернись в PyCharm — авторизация завершена, аккаунт привязан.

---

### Шаг 3. Настройка окружения и установка библиотек
1. Создание виртуального окружения:
   * Если в правом верхнем углу всплывет уведомление: *«Plugins / Requirements: Create virtual environment?»* — нажми **OK / Create**.
   * Если уведомление не появилось:
     * Перейди в настройки: `Шестерёнка в правом верхнем углу (или слева) ➔ Settings`.
     * Выбери слева: `Project: peer-check ➔ Python Interpreter`.
     * Нажми **Add Interpreter ➔ Add Local Interpreter...**
     * Выбери тип **Virtualenv Environment**, путь оставь стандартным (`.venv`), нажми **OK**.
2. Установка библиотек:
   * Открой встроенный терминал в PyCharm: нажми **Alt + F12** (или нажми на вкладку **Terminal** в левом нижнем углу).
   * Убедись, что в начале строки терминала написано `(.venv)`.
   * Введи команду и нажми Enter:
     ```bash
     pip install -r requirements.txt
     ```
   * Дождись окончания загрузки. Теперь проект полностью готов к запуску.

## 1. Начало работы (скачать чужие изменения)
Перед тем как начать писать код в любой день:
1. В правом верхнем углу окна PyCharm нажми на синюю стрелку **Update Project** (или нажми `Ctrl + T`).
2. В появившемся окне просто нажми **OK**.
3. PyCharm скачает свежие изменения, которые успели сделать другие участники команды.

---

## 2. Как сохранить и отправить свою работу (Commit & Push)
Когда файл написан или отредактирован:

1. Открой вкладку **Commit** на панели слева (иконка с зеленой галочкой или нажми `Ctrl + K`).
2. В списке **Changes** убедись, что галочка стоит **только** напротив твоего рабочего файла (`.py` или `.md`).
   *(Сними галочки с папок `.idea`, `.venv` или файлов `.db`, если они случайно там появились).*
3. В поле сообщения напиши, что сделано (например: `подготовлен стартовый каркас интерфейса`).
4. Внизу нажми на стрелочку рядом с синей кнопкой **Commit** и выбери **Commit and Push...** (или нажми `Ctrl + Alt + K`).
5. В открывшемся окне нажми синюю кнопку **Push**.
6. Готово! Твой код отправлен в репозиторий на GitHub.

---

## 3. Что делать, если при Push вылезла ошибка?

Самая частая ситуация: ты нажал Push, а PyCharm написал красную ошибку: **Push rejected** (или предложил сделать Update).
Это абсолютно нормально. Это значит, что кто-то из ребят отправил свой файл чуть раньше тебя.

**Что делать:**
1. Нажми синюю стрелку **Update Project** (`Ctrl + T`) ➔ в окне нажми **OK**.
2. PyCharm сам скачает изменения соседа и аккуратно объединит их с твоими.
3. Снова нажми **Push** (`Ctrl + Shift + K`) ➔ синяя кнопка **Push**. Код успешно уйдет.
