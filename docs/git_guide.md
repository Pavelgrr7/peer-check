# Гайд по настройке и основам Git

> Если проект уже склонирован и настроен, основной рабочий процесс (ветки, коммиты, PR) описан в **[Гайде по повседневной работе](https://github.com/Pavelgrr7/peer-check/blob/main/docs/daily_workflow_guide.md)**.

Все основные кнопки вынесены на верхнюю панель и боковую вкладку **Commit**.


## 0. Первоначальная настройка проекта (Делается один раз)

Если вы еще не скачали проект на свой компьютер, выполните эти шаги:

### Шаг 1. Клонирование репозитория
1. Запустите **PyCharm**.
2. На стартовом экране нажмите кнопку **Clone...** (или в верхнем меню: `File ➔ New ➔ Project from Version Control...`).
3. В поле **URL** вставьте ссылку на наш репозиторий:  
   `https://github.com/Pavelgrr7/peer-check.git`
4. В поле **Directory (Папка)** выберите, куда сохранить проект.  
   *(**Важно для Windows:** путь к папке не должен содержать русских букв. Лучше сохранить, например, в `C:\Projects\PeerCheck`, если у вас имя пользователя содержит кириллицу).*
5. Нажмите кнопку **Clone**.

---

### Шаг 2. Авторизация в GitHub
Когда PyCharm попросит доступ к GitHub (при клонировании или при первой попытке сделать Push):
1. В появившемся окне выберите вариант **Log In via GitHub...** (Войти через GitHub).
2. PyCharm автоматически откроет страницу в вашем браузере.
3. Нажмите кнопку **Authorize**.
4. Вернитесь в PyCharm — авторизация завершена, аккаунт привязан!

---

### Шаг 3. Настройка виртуального окружения
После открытия проекта PyCharm обычно сам замечает файл `requirements.txt` и предлагает создать окружение.
1. Если в правом верхнем углу всплывет уведомление: *«Plugins / Requirements: Create virtual environment?»* — нажмите **OK / Create**.
2. Если уведомление не появилось:
   * Перейдите в настройки: `Шестерёнка слева сверху ➔ Settings`.
   * Слева выберите: `Python ➔ Interpreter`.
   * Нажмите **Add Interpreter ➔ Add Local Interpreter...**
   * Выберите тип **Virtualenv Environment**, путь останется стандартным (`.venv`), нажмите **OK**.
3. Теперь проект полностью настроен и готов к работе!

## 1. Начало работы (Скачать чужие изменения — Pull)
Перед тем как начать писать код в любой день:
1. Откройте проект в PyCharm.
2. В правом верхнем углу окна найдите панель Git и нажмите на **Update Project** (или нажмите `Ctrl + T`).
3. Если появилось диалоговое окно, просто нажмите **OK**.
4. PyCharm скачает все свежие изменения, которые сделали другие участники.

---

## 2. Как сохранить и отправить свою работу (Commit & Push)
Когда вы написали код или отредактировали файл:

1. Откройте вкладку **Commit** на панели слева — иконка с зеленой галочкой/дискетой (или нажмите `Ctrl + K`).
2. В списке **Changes** убедитесь, что стоят галочки напротив ваших измененных файлов.
   *(Следите, чтобы случайно не стояли галочки на системных файлах или папках `.idea`, `.venv`)*.
3. В поле ниже напишите понятное сообщение, что вы сделали.
4. Внизу нажмите на стрелочку рядом с синей кнопкой **Commit** и выберите **«Commit and Push...»** (или нажмите `Ctrl + Alt + K`).
5. В открывшемся окне подтверждения нажмите синюю кнопку **Push**.
6. Готово! Ваш код сразу отправлен на GitHub.

---

## 3. Что делать, если Git ругается или что-то сломалось?
* Скопируйте ваш рабочий файл в другую папку/на рабочий стол, напишите мне в лс и прикрепите скриншот ошибки. 
* Мы все поправим и разберёмся, ваш код никуда не пропадет !
